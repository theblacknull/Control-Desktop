Vercel Sandbox runs a Linux microVM, and agent-desktop runs inside it against the sandbox's own desktop instead of yours. The [`agent-desktop sandbox` commands](/desktop/sandboxes) do not manage Vercel Sandbox; the Vercel SDK creates and drives it.

## Setup

```bash
npm install @vercel/sandbox                                    # the SDK that creates and drives sandboxes
vercel link                                                    # connect this directory to a Vercel project
vercel env pull                                                # writes VERCEL_OIDC_TOKEN to .env.local
```

The SDK reads that token to create sandboxes. On Vercel, the runtime provides the token, so a deployment skips both `vercel` commands.

## Run agent-desktop

`ad-desktop` is an image you build once with a desktop session (Xvfb, D-Bus, AT-SPI, an app such as GNOME Calculator), the agent-desktop Linux binary, and the entrypoint from the [Docker container guide](/desktop/guides/docker-container). Vercel Sandbox does not run the image's entrypoint, so start it yourself in each new or resumed sandbox.

```typescript
import { Sandbox } from "@vercel/sandbox";

// 1. Create a named sandbox from the desktop image (persistent by default)
const sandbox = await Sandbox.create({ name: "ad-demo", image: "ad-desktop" });

// 2. Start the desktop session and wait for it to write its display and bus address
await sandbox.runCommand({ cmd: "/usr/local/bin/agent-desktop-entrypoint", detached: true });
await sandbox.runCommand({ cmd: "sh", args: ["-c", "until test -s /run/agent-desktop/env; do sleep 1; done"] });

// 3. Open the app and read its tree inside that session
await sandbox.runCommand({ cmd: "sh", args: ["-c", ". /run/agent-desktop/env && agent-desktop launch gnome-calculator"] });
const result = await sandbox.runCommand({
  cmd: "sh",
  args: ["-c", ". /run/agent-desktop/env && agent-desktop snapshot --app gnome-calculator -i --compact"],
});

// 4. Check the result - one JSON envelope per command
console.log(result.exitCode); // 0
console.log(JSON.parse(await result.stdout()).data.ref_count); // 27

// 5. Later, resume the same sandbox by name and repeat step 2
const same = await Sandbox.get({ name: "ad-demo" });
```

Every command returns one JSON envelope, the same as on your own machine; [JSON output](/desktop/json-output) describes the fields.
